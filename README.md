# Inti Ruchulu

A modern React + TypeScript e-commerce application built for a traditional homemade Telugu food business.

The application allows customers to browse authentic homemade pickles, podis (spice powders), and traditional food products, customize product weights, manage a shopping cart, and experience a fast, responsive shopping experience.

# Getting Started

## Clone Repository

```bash
git clone https://github.com/Anudepp/intiruchulu.git
```

---

## Navigate into Project

```bash
cd intiruchulu
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

Application runs at

```
http://localhost:5173
```
